[verse]

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

By default, the output is a human-readable text tree with box-drawing characters.
Use `--json` for machine-readable JSON output.

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help
--json:: Output as JSON instead of human-readable tree
--workspace <workspace>:: Only show tree for specified workspace
--focused:: Only show tree for the focused workspace
--floating-windows-as-tiling-windows:: Include floating windows as children of the root tiling container instead of a separate section
// end::body[]
